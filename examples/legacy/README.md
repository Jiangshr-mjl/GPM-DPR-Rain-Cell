# 历史脚本归档

本目录保留原仓库中的旧版绘图、统计脚本，便于对照历史分析过程；文件内容未改写，**不属于当前可运行/已测试的识别流程**。

| 文件 | 限制 |
| --- | --- |
| `RCplot.py` | 面向旧雨团字典；缺少部分 Matplotlib/Cartopy 导入 |
| `绘制单个雨团.py` | 依赖 `备份代码.RC_processing` 和旧 `.npy` 字典，包含固定路径和顶层绘图调用 |
| `统计雨团数量.py` | 依赖旧 `.npy` 字典结构，包含顶层数据加载/调试语句 |

从仓库根目录移至此处后，这些脚本中的相对路径也未自动调整。请勿直接导入或执行；需要迁移分析时，先按根目录 README 读取新的 NetCDF 结果。

旧脚本使用 `np.load(..., allow_pickle=True)`，只能用于可信来源的数据。新识别流程不依赖 pickle。

历史示例图片仍保留在根目录的 `Figure/`，GPM 参考资料仍保留在 `Document/`。图片不表示由本次整理后的实现重新计算得到。
